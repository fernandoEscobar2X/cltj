# CorteLaser TJ

Sitio comercial para cotizar corte y grabado laser en Tijuana.
Dirigido a negocios, eventos y clientes que requieren piezas personalizadas.

## Stack
- React
- Vite
- Tailwind CSS
- Framer Motion
- React Router
- Lenis
- React Helmet Async
- Netlify

## Funcionalidades principales
- Landing con servicios, proceso, prueba social y CTA a WhatsApp.
- Galeria filtrable de trabajos y piezas destacadas.
- Lightbox para revisar proyectos del portafolio.
- SEO basico con metadatos por ruta.
- Experiencia responsive con navegacion movil y animaciones.
